# 第二题作答导览

**一句话方案**：Greenhouse OS 一期不追求功能多，而是把一条闭环跑真——番茄智轨产线的"生产计划 → 环境/水肥目标带下发 → 作业执行反馈 → 生育期推进 → 采收轮次确认 → 批次关闭归档"。平台只做决策协调（受理—计划—事件—证据），实时控制与安全互锁留在现场，AI 以可替换插件接入且失效可降级。

## 与第一题的关系

第一题通过公开检查器验证了"受理—计划—事件—证据"的边界语义：计划完成不等于设备已执行、下发幂等（duplicate/conflict）、事件归属一致。第二题将这些已验证语义直接沉淀为 Greenhouse OS 目标带与任务模型的基础（见 02 §4、§10），两题是同一套平台思想从模拟到生产的延续。
